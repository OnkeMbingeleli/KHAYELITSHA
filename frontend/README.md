# Taxi Management System - Frontend

## Overview
This is the frontend for the Taxi Management System, a single-page application (SPA) built with vanilla HTML, CSS, and JavaScript. It connects to the backend API for data operations.

## Features
- User login/logout
- Record pickups
- View daily summaries
- Mobile-responsive design

## Files
- `index.html`: Main HTML structure
- `style.css`: Styling
- `script.js`: JavaScript for API calls and UI logic

## Setup
1. Ensure backend is running on http://127.0.0.1:5000
2. Open `index.html` in a browser
3. Login with marshal1/pass

## Notes
- Uses fetch API for backend communication
- CORS may need to be enabled on backend for cross-origin requests
- For production, host on a web server and use HTTPS
